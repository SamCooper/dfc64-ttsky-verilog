The main control logic verilog [file](src/dfc64_control_unit.v) is to be autogenerated so that populating the micro_rom stages and the associated dispatch case statements is easier to update and keep in-sync. The desire is that adding extra opcodes or extra fields to the stages is simplified.

There shall be a python script that is executed as part of the build steps in the test Makefile that uses a JSON file containing the microcode stages for each opcode along with some other source files and combine them into the desired verilog source file.

The script shall take sections of fixed verilog code held in files, combined with generated verilog code driven by a JSON data file, to create the complete control logic verilog file. The script shall contain a list of default values for each of the parts of the microcode stages including the name of the output register, the size of the field, and the default value. The JSON file will provide the actual stages of each opcode/addressing mode combination as overrides to the default (so the JSON only needs to provide the fields that are not default). The fields in the dict will drive the generation of the parts of the verilog file, so adding a new entry will increate the size of the microcode structure and generated stages.

Stages to implement:

- Create a dummy python script that is invoked by the test Makefile before the verilog compilation step
- Update the python script to read a set of partial verilog source files and output them into a destination file. The list of source files shall be held in a list and the destination file shall be held in a variable. There is no need to have these values configurable at runtime, they can be set in the python code.
- read the proposed [JSON file](src/opcode_stages.json) and use this to build:
  - a list of entries for the fields of the microcode stages. It shall be derived from the original control unit source and created in the script.
  - a generator that shall replace the module output registers
  - a generator for the localparam MICRO_ROM_WORD_SIZE definition
  - a generator for the micro_rom entries for each of the opcodes in the JSON file
  - a generator for the case statements that set the dispatch address for each of the opcodes
  - a generator for the final assign statements from the current_micro_word entry to the output module registers
- update the proposed JSON file with the opcodes and stages from the original control unit source microcode.
